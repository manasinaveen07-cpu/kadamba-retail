# Kadamba Group — Retail Redesign & 3D Interactive Web Experience

A modern redesign of the **Kadamba Group Retail Enterprise** (Sirsi, Karnataka) built with the **Kadamba Heritage Bazaar** design system, interactive 3D Three.js product inspection models, dynamic compounding wealth vault, and interconnected multi-page navigation.

## 🌟 Live Pages Included

- **Home (`index.html`)** — Flagship retail hero with real-time 3D Kadamba emblem, orbiting spice particles, 4 enterprise pillars, and WhatsApp Santhe Express ordering.
- **Supermart (`supermart.html`)** — 11,000+ SKU departmental shelves, category filters, interactive add-to-cart steppers, and 360° 3D product inspection.
- **Financial Services (`financial-services.html`)** — Kadamba Souharda Sahakari portal with an interactive 3D dividend coin stack and compound deposit interest calculator.
- **FMCG Suppliers (`suppliers.html`)** — Regional B2B distribution network (1,200+ partners) with an interactive quotation builder.
- **Store Locations (`stores.html`)** — Flagship College Road Sirsi complex and regional santhe hubs.
- **About Us (`about-us.html`)** — Cooperative heritage since 1998, APMC yard licensing, and board of directors.
- **Privacy Policy (`privacy-policy.html`)** — Member data charter and regulatory guidelines.

## 🚀 Running Locally

```bash
# Start the local server
npm start
# or: node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack

- **Tailwind CSS** (CDN) with custom Kadamba Heritage Bazaar color & font tokens
- **Three.js** (r128) for real-time 3D lighting, physics, and 360° packaging models
- **Outfit & Plus Jakarta Sans** typography
- **Google Material Symbols**
